# Ploopy Adept Ergo 8

Stock Madromys R1.001+ PCB with SW5 and SW7 populated (eight buttons), wired to a custom
ergonomic top. The LAYOUT_ergo macro lists the keys in physical order:
left top, left middle, thumb outer, thumb inner, right top, right middle,
right bottom inner, right bottom outer.

Build: `qmk compile -kb ploopyco/madromys/rev1_001_ergo -km via`

See the [main readme](../readme.md) for bootloader entry (short the two gold vias while plugging in).
