# STL files

Three printed parts make up the shell, plus the keycaps in [`keycaps/`](keycaps/).

| File | Part | Notes |
|---|---|---|
| `bottom.stl` | Bottom shell | Holds the Madromys PCB, the eight Omron D2LS-21 switches and the sensor. |
| `top.stl` | Top shell | Ergo button layout: two stacked buttons on the left, two thumb keys, two stacked on the right, two side by side below them. |
| `cradle.stl` | Ball cradle | Sits in the top shell and carries the three bearings for the 44 mm ball. |

The editable Fusion 360 source is in [`../fusion/`](../fusion/).
